  <action>
Create CollectionsController following the StatusController pattern:

```java
public class CollectionsController {
    private final Collections plugin;
    private final MainThreadBridge mainThreadBridge;

    public CollectionsController(Collections plugin, MainThreadBridge mainThreadBridge) {
        this.plugin = plugin;
        this.mainThreadBridge = mainThreadBridge;
    }

    public void register(Javalin app) {
        app.get("/api/collections", this::listCollections);
        app.get("/api/collections/{id}", this::getCollection);
    }
}
```

**listCollections(Context ctx):**
1. Use `mainThreadBridge.callSync()` with 2000ms timeout
2. Inside callSync: `plugin.getCollectionManager().getAllCollections().values()`
3. Map each Collection to CollectionSummary using a helper method
4. Sort by name alphabetically
5. Return as JSON via `ctx.json(summaries)`
6. Catch MainThreadException and throw `InternalServerErrorResponse("Server busy, please retry")`

**getCollection(Context ctx):**
1. Get ID from `ctx.pathParam("id")`
2. Use `mainThreadBridge.callSync()` with 2000ms timeout
3. Inside callSync: `plugin.getCollectionManager().getCollection(id)`
4. If null, return null from callSync
5. If result is null, throw `NotFoundResponse("Collection not found: " + id)`
6. Map Collection to CollectionDetail using helper method
7. Return as JSON via `ctx.json(detail)`

**Helper methods:**
- `toSummary(Collection c)` - Maps Collection to CollectionSummary
- `toDetail(Collection c)` - Maps Collection to CollectionDetail with nested ItemSummary and RewardSummary

Use `c.tier().name()`, `c.icon().name()`, `i.material().name()` to convert enums to strings for JSON.
