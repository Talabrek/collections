2. In Storage.java interface, add method:
   ```java
   /**
    * Get all player UUIDs in the database for streaming export.
    * Returns a list to allow cursor-based iteration without loading all data.
    * @return CompletableFuture containing list of all player UUIDs
    */
   CompletableFuture<List<UUID>> getAllPlayerUuids();
   ```

3. In SQLiteStorage.java, implement getAllPlayerUuids():
   ```java
   @Override
   public CompletableFuture<List<UUID>> getAllPlayerUuids() {
       return CompletableFuture.supplyAsync(() -> {
           List<UUID> uuids = new ArrayList<>();
           try (Connection conn = dataSource.getConnection();
                Statement stmt = conn.createStatement();
                ResultSet rs = stmt.executeQuery("SELECT uuid FROM players")) {
               while (rs.next()) {
                   uuids.add(UUID.fromString(rs.getString("uuid")));
               }
           } catch (SQLException e) {
               plugin.getLogger().log(Level.WARNING, "Failed to get all player UUIDs", e);
           }
           return uuids;
       });
   }
   ```
