<objective>
Make PlayerProgress internal state thread-safe

Purpose: PlayerProgress uses plain HashMap and HashSet which are not thread-safe. The object is created on async thread (database load), accessed from main thread (GUI, commands), and potentially read from multiple threads. Without thread-safe collections, concurrent access can cause data corruption or infinite loops.

Output: PlayerProgress with ConcurrentHashMap for collections and ConcurrentHashMap.newKeySet() for collectedItems.
</objective>
