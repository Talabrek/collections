Create CollectionValidator class that validates CollectionRequest and returns field-specific errors:

```java
public class CollectionValidator {
    private final List<FieldError> errors = new ArrayList<>();

    public ValidationResult validate(CollectionRequest request) { ... }

    public record ValidationResult(boolean valid, List<FieldError> errors) {
        public static ValidationResult valid() { return new ValidationResult(true, List.of()); }
        public static ValidationResult invalid(List<FieldError> errors) { return new ValidationResult(false, errors); }
    }
}
```

Validation rules:
1. **id**: Required, must match pattern `^[a-z0-9_]+$` (lowercase alphanumeric + underscore, no dots/slashes for path traversal prevention)
2. **name**: Required, non-blank
3. **tier**: If provided, must be valid CollectibleTier enum value (case-insensitive)
4. **icon**: If provided, must be valid Material enum value (case-insensitive)
5. **items**: Required, must have at least 1 item
6. For each item:
   - id: Required, valid format
   - name: Required
   - material: If provided, valid Material
   - weight: Must be > 0

Field path notation for nested errors: "items[0].material", "items[1].name"

Use Material.valueOf() and CollectibleTier.valueOf() for enum validation - catch IllegalArgumentException.
  </action>
