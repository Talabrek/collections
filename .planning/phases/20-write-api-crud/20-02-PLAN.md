  <name>Task 1: Add write endpoints to CollectionsController</name>
  <files>src/main/java/com/blockworlds/collections/web/api/CollectionsController.java</files>
  <action>
Extend CollectionsController with CRUD operations. Add these instance fields:
- private final CollectionValidator validator = new CollectionValidator();
- private final CollectionYamlWriter yamlWriter = new CollectionYamlWriter();

Add to register() method:
```java
app.post("/api/collections", this::createCollection);
app.put("/api/collections/{id}", this::updateCollection);
app.delete("/api/collections/{id}", this::deleteCollection);
app.post("/api/reload", this::reloadCollections);
```

**createCollection(Context ctx):**
1. Parse body: `ctx.bodyAsClass(CollectionRequest.class)` with try/catch for BadRequestResponse
2. Validate: `validator.validate(request)` - return 400 + ValidationErrorResponse if invalid
3. On main thread via mainThreadBridge.runSyncAndWait():
   a. Check duplicate: if plugin.getCollectionManager().hasCollection(request.id()) -> throw for 409
   b. File path: new File(plugin.getDataFolder(), "collections/" + request.id() + ".yml")
   c. Write: yamlWriter.write(request, file)
   d. Reload: plugin.getCollectionManager().loadCollections()
4. Return 201 with {"success": true, "id": request.id()}

Error handling pattern for main thread exceptions:
- "CONFLICT:{id}" -> ConflictResponse
- "IO_ERROR" -> InternalServerErrorResponse("Failed to save collection")
- Timeout -> InternalServerErrorResponse("Server busy")

**updateCollection(Context ctx):**
1. Get id from path: ctx.pathParam("id")
2. Parse and validate request
3. Verify id in body matches path (or body id is null) - else BadRequestResponse
4. On main thread:
   a. Check exists: if NOT hasCollection(id) -> throw for 404
   b. Write file (overwrites)
   c. Reload
5. Return 200 with {"success": true, "id": id}

**deleteCollection(Context ctx):**
1. Get id from path
2. Validate id format: must match ^[a-z0-9_]+$ - else BadRequestResponse (path traversal prevention)
3. On main thread:
   a. Check exists -> 404 if not
   b. Delete file: file.delete() -> InternalServerErrorResponse if fails
   c. Reload
4. Return 204 No Content

**reloadCollections(Context ctx):**
1. On main thread: plugin.getCollectionManager().loadCollections()
2. Get count: plugin.getCollectionManager().getAllCollections().size()
3. Return 200 with {"success": true, "collectionCount": count}

Use Javalin's exception classes:
- BadRequestResponse for invalid JSON/format
- ConflictResponse (409) for duplicate ID
- NotFoundResponse for missing collection
- InternalServerErrorResponse for server errors

/**

 * Prevents path traversal attacks by ensuring ID contains only safe characters.

}
