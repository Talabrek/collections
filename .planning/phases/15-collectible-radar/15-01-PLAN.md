Create RadarManager.java in manager/ package:

1. Track active boss bars in Map<UUID, BossBar> using ConcurrentHashMap
2. Implement showRadar(Player player):
   - Create BossBar using Adventure API: BossBar.bossBar(Component, progress, color, overlay)
   - Initial text: "Radar Loading..."
   - Progress: 1.0f (fixed, use color for tier indication)
   - Overlay: BossBar.Overlay.PROGRESS
   - Store in map and call player.showBossBar(bar)
3. Implement hideRadar(Player player):
   - Get bar from map by UUID, call player.hideBossBar(bar), remove from map
4. Implement updateRadar(Player player, int count, String directionIndicator, CollectibleTier highestTier):
   - Get existing bar from map
   - Build title: "{count} nearby {directionIndicator}" using Component.text()
   - Color mapping: COMMON=WHITE, UNCOMMON=GREEN, RARE=BLUE, EPIC=PURPLE, LEGENDARY=YELLOW, EVENT=PINK
   - Call bar.name(title), bar.color(color)
5. Implement hasRadar(Player player): return activeBars.containsKey(player.getUniqueId())
6. Implement cleanup(Player player): Same as hideRadar but safe if not present

Create RadarTask.java in task/ package following ParticleTask pattern:

1. Fields: plugin, spawnManager, goggleManager, radarManager, configManager, ScheduledTask task
2. Constructor takes Collections plugin, gets managers from plugin
3. Implement start():
   - Get interval from config (radar.update-interval-ticks, default 10)
   - Use Bukkit.getGlobalRegionScheduler().runAtFixedRate() like ParticleTask
   - Initial delay 20L ticks
4. Implement stop(): cancel task if not null
5. Implement updateAllRadars():
   - For each online player with hasRadar():
     - Get nearby collectibles using getNearbyVisibleCollectibles(player, range)
     - Calculate count and direction to nearest
     - Determine highest tier among visible collectibles
     - Call radarManager.updateRadar()
6. Implement getNearbyVisibleCollectibles(Player, rangeBlocks):
   - Get player chunk coords
   - Call spawnManager.getCollectiblesNearChunk() with chunk radius = (rangeBlocks >> 4) + 1
   - Filter: same world, within range (distanceSquared), goggleManager.canPlayerSeeCollectible()
   - Return filtered list
7. Implement getDirectionIndicator(Player player, Location target):
   - Calculate dx = target.X - player.X, dz = target.Z - player.Z
   - Angle to target: Math.toDegrees(Math.atan2(-dx, dz))
   - Normalize player yaw to 0-360
   - Relative angle = ((angleToTarget - playerYaw + 540) % 360) - 180
   - Return "[^]" if Math.abs(relativeAngle) < 45, "[>]" if > 0, "[<]" if < 0
