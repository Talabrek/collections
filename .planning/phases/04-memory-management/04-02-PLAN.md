# 04-02: Add onDisable Cleanup for Listener and GUI Maps

## Objective

Add shutdown() methods to clear per-player maps during plugin disable, preventing memory leaks across `/reload` cycles.

## Context

During server shutdown, players are not processed through PlayerQuitEvent, so any remaining entries in per-player maps are not cleaned. While the JVM shutting down handles this case, `/reload` creates a new plugin instance while the old data remains in memory until GC.

The following maps need explicit clearing in onDisable:
- `CollectibleInteractListener.lastCollectTime` - player cooldown timestamps
- `CollectibleInteractListener.collectLocks` - if applicable (verify in Plan 01)
- `GUIManager.openGuis` - player GUI tracking

Research reference: `.planning/phases/04-memory-management/04-RESEARCH.md`
