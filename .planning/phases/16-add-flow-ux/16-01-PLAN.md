Create new AddPreviewGUI.java implementing GUIHolder interface. Use 54-slot (6-row) layout:

Layout:
- Row 0 (slots 0-8): Filler border
- Row 1 (slots 9-17): [filler] [7 collection item slots: 10-16] [filler]
- Row 2 (slots 18-26): [filler] [7 collection item slots: 19-25] [filler]
- Row 3 (slots 27-35): [filler] [7 collection item slots: 28-34] [filler]
- Row 4 (slots 36-44): [filler x4] [INFO slot 40] [filler x4]
- Row 5 (slots 45-53): [filler] [filler] [YES slot 47] [filler] [ITEM slot 49] [filler] [NO slot 51] [filler] [filler]

Constants:
```java
private static final int INVENTORY_SIZE = 54;
private static final int[] ITEM_SLOTS = {10,11,12,13,14,15,16, 19,20,21,22,23,24,25, 28,29,30,31,32,33,34};
private static final int INFO_SLOT = 40;
private static final int ITEM_DISPLAY_SLOT = 49;
private static final int CONFIRM_SLOT = 47;
private static final int CANCEL_SLOT = 51;
```

Constructor: Same signature as ConfirmAddGUI - (Collections plugin, Player player, ItemStack itemToAdd, Collection collection, CollectionItem collectionItem). Store all fields, create inventory with title "<gold>Add to {collection.name()}?</gold>".

Methods to implement:

1. `open()` - Call populateInventory(), registerGUI, openInventory, playOpenSound (copy pattern from CollectionDetailGUI).

2. `populateInventory()`:
   - Fill all slots with guiManager.createFiller()
   - Get PlayerProgress for player
   - Determine hasProgress = progress.getCollectedCount(collection.id()) > 0
   - Loop through collection.items() up to ITEM_SLOTS.length:
     - For each item, call createSlotItem(item, collected, isItemBeingAdded, hasProgress)
     - Set in ITEM_SLOTS[i]
   - Set INFO_SLOT = createInfoItem()
   - Set ITEM_DISPLAY_SLOT = itemToAdd (the actual item being added)
   - Set CONFIRM_SLOT = guiManager.createConfirmButton()
   - Set CANCEL_SLOT = guiManager.createCancelButton()

3. `createSlotItem(CollectionItem item, boolean collected, boolean isItemBeingAdded, boolean hasProgress)`:
   - If isItemBeingAdded: Return ItemBuilder.of(item.material()).name("<green>" + item.name() + "</green>").addLore("<gray>-----</gray>").addLore("<yellow>Adding this item!</yellow>").glowing().build()
   - Else if collected: Return ItemBuilder.of(item.material()).name("<gold>" + item.name() + "</gold>").addLore("<green>Collected</green>").build()
   - Else if hasProgress: Return ItemBuilder.of(Material.GRAY_STAINED_GLASS_PANE).name("<yellow>" + item.name() + "</yellow>").addLore("<red>Not yet found</red>").build()
   - Else: Return ItemBuilder.of(Material.GRAY_STAINED_GLASS_PANE).name("<gray>???</gray>").addLore("<dark_gray>Collect items to reveal</dark_gray>").build()

4. `createInfoItem()`:
   - Get progress, calculate collected count and total
   - Calculate afterAdd = collected + 1
   - Build lore:
     - "<gray>-----</gray>"
     - "<white>Progress: " + guiManager.createProgressBar(collected, total, 10) + "</white>"
     - ""
     - "<yellow>After adding:</yellow>"
     - "<white>" + guiManager.createProgressBar(afterAdd, total, 10) + "</white>"
     - If afterAdd >= total, add: "", "<green>This will complete the collection!</green>"
   - Return ItemBuilder.of(Material.PAPER).name("<gold>" + collection.name() + "</gold>").lore(lore).build()

5. `handleClick(InventoryClickEvent event)`:
   - event.setCancelled(true)
   - Get slot, return if < 0 or >= INVENTORY_SIZE
   - playClickSound
   - If slot == CONFIRM_SLOT: call confirmAdd() (leave stub for now - Plan 02 will implement transition)
   - If slot == CANCEL_SLOT: call cancel()

6. `confirmAdd()` - For now, just call player.closeInventory() and send a placeholder message. Plan 02 will implement the full logic with transition.

7. `cancel()` - Copy from ConfirmAddGUI: player.closeInventory(), send "add-cancelled" message.

8. `handleClose(InventoryCloseEvent event)` - Empty, nothing special needed.

9. `getType()` - Return GUIType.ADD_PREVIEW

10. `getInventory()` - Return inventory

Also update GUIType.java to add ADD_PREVIEW enum value after CONFIRM_ADD.
