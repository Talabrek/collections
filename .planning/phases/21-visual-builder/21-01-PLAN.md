1. In register() method, add: `app.get("/api/materials", this::listMaterials);`

2. Add listMaterials handler method:
```java
private void listMaterials(Context ctx) {
    // No main thread needed - Material enum is static
    List<String> materials = Arrays.stream(Material.values())
        .filter(m -> !m.isLegacy())
        .filter(Material::isItem)
        .map(Material::name)
        .sorted()
        .toList();
    ctx.json(materials);
}
```

3. Add import for `org.bukkit.Material` and `java.util.Arrays` if not present.

This endpoint is fast (enum iteration) and does not need MainThreadBridge since Material is a static enum.
