Create the `web` package with three core classes:

**WebPanelManager.java:**
- Constructor takes Collections plugin instance
- `start(int port)` method:
  1. Store current classloader: `Thread.currentThread().getContextClassLoader()`
  2. Set plugin classloader: `Thread.currentThread().setContextClassLoader(plugin.getClass().getClassLoader())`
  3. In try-finally block, create Javalin instance with config:
     - `config.showJavalinBanner = false`
     - `config.jetty.modifyServer(server -> server.setStopTimeout(5000))`
  4. Restore original classloader in finally block
  5. Log "Web panel started on port X"
- `stop()` method:
  1. If app not null, call `app.stop()`
  2. Set app = null
  3. Log "Web panel stopped"

**WebPanelConfig.java:**
- `ensurePasswordConfigured(FileConfiguration config, Plugin plugin)` method:
  1. Check if `web-panel.password-hash` exists and is non-empty
  2. If missing/empty, generate 16-char random password using SecureRandom
  3. Hash with BCrypt: `BCrypt.withDefaults().hashToString(12, password.toCharArray())`
  4. Save hash to config, call `plugin.saveConfig()`
  5. Log WARNING with generated password (shown only once)
- `hashPassword(String password)` static method for manual password setting
- Use characters: `ABCDEFGHJKLMNPQRSTUVWXYZabcdefghjkmnpqrstuvwxyz23456789` (no ambiguous chars like 0/O, 1/l)

**MainThreadBridge.java:**
- Constructor takes Plugin instance
- `callSync(Supplier<T> task, long timeoutMs)` method:
  1. If already on main thread (`Bukkit.isPrimaryThread()`), execute directly
  2. Otherwise use `CompletableFuture` + `Bukkit.getScheduler().runTask()`
  3. Use `future.get(timeoutMs, TimeUnit.MILLISECONDS)` with timeout
- `runSync(Runnable task)` method for fire-and-forget (no return value)

**Add field:**

**In onEnable(), after metricsManager initialization (before registerCommands):**
```java
// Initialize web panel (after configManager)
if (configManager.isWebPanelEnabled()) {
    WebPanelConfig webPanelConfig = new WebPanelConfig();
    webPanelConfig.ensurePasswordConfigured(getConfig(), this);

    this.webPanelManager = new WebPanelManager(this);
    webPanelManager.start(configManager.getWebPanelPort());
}
```

**In onDisable(), as FIRST shutdown action (before radarTask.stop()):**
```java
// Stop web panel FIRST (release port for reload)
if (webPanelManager != null) {
    webPanelManager.stop();
    webPanelManager = null;
}
```

**Add getter:**
```java
public WebPanelManager getWebPanelManager() {
    return webPanelManager;
}
```

Note: Web panel does NOT restart on `/collections reload` - password changes require full server restart. This is intentional (stateless server, no live config changes needed).
