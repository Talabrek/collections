  <action>
Add a new "## Web Admin Panel" section after the "## Features" section. Include:

1. **Feature Overview** - Brief description of the web panel:
   - Visual collection management
   - Full CRUD operations (create, edit, delete collections)
   - Drag-drop item builder with material browser
   - Template-based collection creation
   - MiniMessage live preview
   - Weight percentage validation
   - Live reload to apply changes

2. **Setup Instructions** - Step-by-step setup:
   - Enable in config.yml: `web-panel.enabled: true`
   - Configure port (default 8080)
   - Configure bind address (localhost vs all interfaces)
   - First run generates password (shown in console)
   - Access at http://localhost:8080 (or configured host:port)
   - Login with admin username and generated password

3. **Configuration Reference** - Show the config.yml settings:
   ```yaml
   web-panel:
     enabled: false           # Set to true to enable
     port: 8080               # Web server port
     bind-address: "127.0.0.1" # 0.0.0.0 for all interfaces
     password-hash: ""        # Auto-generated, do not edit
   ```

4. **Security Notes**:
   - Password is BCrypt hashed (never stored plaintext)
   - Default bind to localhost only (127.0.0.1)
   - Use reverse proxy with HTTPS for remote access
   - To reset password: delete password-hash line and restart

Use existing README structure and formatting conventions.
