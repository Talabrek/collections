<objective>
Implement blocking saves on player quit to prevent data loss from fire-and-forget async operations.

Purpose: Currently `onPlayerQuit` fires `saveAndUnload()` without waiting for completion. If save takes 2 seconds and player rejoins in 1 second, the new load races with the old save, potentially causing data loss. Blocking ensures save completes before the event handler returns.

Output: Modified `PlayerListener.java` that blocks on quit saves with a 5-second timeout, logging SEVERE on timeout or failure.
</objective>

3. Replace fire-and-forget save with blocking call:
   ```java
   @EventHandler(priority = EventPriority.HIGHEST)
   public void onPlayerQuit(PlayerQuitEvent event) {
       Player player = event.getPlayer();
       UUID playerId = player.getUniqueId();

       // Clean up cooldown tracking first (non-critical, fast)
       CollectibleInteractListener interactListener = plugin.getCollectibleInteractListener();
       if (interactListener != null) {
           interactListener.cleanupPlayer(playerId);
       }

       // Block until save completes with timeout
       try {
           playerDataManager.saveAndUnload(playerId)
               .get(5, TimeUnit.SECONDS);

           if (plugin.getConfigManager().isDebugMode()) {
               plugin.getLogger().info("Saved and unloaded data for " + player.getName());
           }
       } catch (TimeoutException e) {
           plugin.getLogger().log(Level.SEVERE,
               "Save timed out for player " + playerId + " - data may be lost");
       } catch (Exception e) {
           plugin.getLogger().log(Level.SEVERE,
               "Save failed for player " + playerId, e);
       }
   }
   ```

Key changes:
- HIGHEST priority ensures save runs before other quit handlers that might interfere
- `.get(5, TimeUnit.SECONDS)` blocks the main thread until save completes or times out
- 5 seconds is safety margin (normal saves complete in <100ms)
- SEVERE logging on timeout/failure for visibility
- Debug logging moved inside try block to only log on success
