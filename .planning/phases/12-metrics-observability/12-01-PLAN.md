Create MetricsManager class with:

1. **AtomicLong counters** for thread-safe tracking:
   - `itemsCollected` - items added to journals
   - `collectionsCompleted` - collections marked complete
   - `spawnAttempts` - total spawn attempts
   - `spawnSuccesses` - successful spawns
   - `spawnFailures` - failed spawns

2. **Increment methods** for hook points:
   - `recordItemCollected()` - increments itemsCollected
   - `recordCollectionCompleted()` - increments collectionsCompleted
   - `recordSpawnAttempt(boolean success)` - increments appropriate counters

3. **Getter methods** for counters:
   - `getItemsCollected()`, `getCollectionsCompleted()`
   - `getSpawnSuccessRate()` - returns percentage as double

4. **bStats initialization** in constructor:
   - Use placeholder plugin ID (12345) - user will update after registration
   - Add SimplePie for storage_type (sqlite/mysql)
   - Add SimplePie for collection_count (buckets: 1-5, 6-10, 11-20, 20+)
   - Add SimplePie for spawn_success_rate (buckets: 90-100%, 70-89%, 50-69%, Below 50%)

5. **Config integration**:
   - Check `config.getBoolean("metrics.enabled", true)` before initializing bStats
   - Store the plugin ID in config as `metrics.bstats-id` with default 12345

Pattern from research:
```java
public class MetricsManager {
    private static final int DEFAULT_BSTATS_ID = 12345; // Replace after registration

    private final AtomicLong itemsCollected = new AtomicLong(0);
    // ... other counters

    public MetricsManager(Collections plugin) {
        boolean metricsEnabled = plugin.getConfigManager().getBoolean("metrics.enabled", true);
        if (metricsEnabled) {
            int pluginId = plugin.getConfigManager().getInt("metrics.bstats-id", DEFAULT_BSTATS_ID);
            Metrics metrics = new Metrics(plugin, pluginId);
            setupCustomCharts(metrics, plugin);
        }
    }
}
```

Import: `org.bstats.bukkit.Metrics`, `org.bstats.charts.SimplePie`
